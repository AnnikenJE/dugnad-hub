## 🌸 Case: DugnadHub
**Application for organizing and managing volunteer activities.**

DugnadHub is a cross-platform application developed with React Native and Firebase, designed to simplify the organization and coordination of volunteer activities (dugnader). The app allows users to create, browse, and participate in dugnader, making it easier to manage participation in a structured and user-friendly way.

The application supports **iOS and web platforms** and includes **Google authentication and email/password login**. Firebase is used for **authentication, database management, and image storage**, enabling users to upload and display images related to dugnader. The app focuses on usability, clean code structure, and reusable components.
